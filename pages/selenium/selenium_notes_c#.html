WebDriver Methods

WebDriver Methods

These methods are used to control the browser and manage the WebDriver instance:

  1. Navigate().GoToUrl(string url): Opens the specified URL in the browser.
  2. Url: Returns the current URL of the browser.
  3. Title: Returns the title of the current page.
  4. FindElement(By by): Finds the first WebElement using the given method.
  5. FindElements(By by): Finds all WebElements using the given method.
  6. PageSource: Returns the source code of the current page.
  7. Close(): Closes the current browser window.
  8. Quit(): Closes all browser windows and ends the WebDriver session.
  9. WindowHandles: Returns a list of window handles for all open browser windows.
  10. CurrentWindowHandle: Returns the window handle of the current window.
  11. SwitchTo(): Switches to a different frame, window, or alert.
    • SwitchTo().Frame()
    • SwitchTo().Window()
    • SwitchTo().Alert()
  12. Navigate(): Allows navigation to and from web pages.
    • Navigate().GoToUrl(string url)
    • Navigate().Back()
    • Navigate().Forward()
    • Navigate().Refresh()
  13. Manage(): Provides various options to manage the browser.

    • Manage().Timeouts()

      • ImplicitWait = TimeSpan duration: Sets the amount of time the driver should wait when searching for an element if it is not immediately present; use this to handle situations where elements take time to appear.
        • Scenario: When elements on a page load asynchronously and you want to ensure that WebDriver waits long enough to find all elements without throwing an exception immediately.
      • PageLoad = TimeSpan duration: Sets the maximum amount of time to wait for a page to load before throwing an error; use this to handle slow-loading pages.
        • Scenario: When navigating to a webpage that might take a longer time to load due to heavy content or slow server response.
      • AsynchronousJavaScript = TimeSpan duration: Sets the amount of time to wait for an asynchronous script to finish execution before throwing an error; use this for operations that involve executing JavaScript with a delay.
        • Scenario: When executing JavaScript code via ExecuteAsyncScript that involves asynchronous operations, such as AJAX calls, which might take some time to complete.

    • Manage().Window()

      Here are concise explanations of each sub-method of Manage().Window():

      • Maximize(): Maximizes the browser window to fill the screen.
      • Minimize(): Minimizes the browser window to the taskbar.
      • FullScreen(): Switches the browser window to full-screen mode.
      • Position = Point targetPosition: Sets the browser window's position to specified x and y coordinates.
      • Size = Size targetSize: Sets the browser window's size to the specified width and height.
      • Position: Returns the current position of the browser window as a Point object.
      • Size: Returns the current size of the browser window as a Size object.

    • Manage().Cookies()

      Here are concise explanations of each sub-method of Manage().Cookies():

      • AddCookie(Cookie cookie): Adds a specified cookie to the current domain.
      • DeleteCookie(Cookie cookie): Deletes a specified cookie from the current domain.
      • DeleteCookieNamed(string name): Deletes a cookie by its name.
      • DeleteAllCookies(): Deletes all cookies from the current domain.
      • GetCookieNamed(string name): Returns the cookie with the specified name.
      • AllCookies: Returns a set of all cookies for the current domain.
  14. ExecuteScript(string script, params object[] args): Executes JavaScript in the context of the current window or frame.
  15. ExecuteAsyncScript(string script, params object[] args): Executes asynchronous JavaScript in the context of the current window or frame.
WebElement Methods
  1. Click(): Clicks on the element.
  2. Submit(): Submits a form.
  3. SendKeys(string keys): Sends a sequence of keystrokes to the element.
  4. Clear(): Clears the content of a text field or text area.
  5. Selected: Checks if the element is selected.
    • Returns a bool indicating whether the element is selected.
  6. Enabled: Checks if the element is enabled.
    • Returns a bool indicating whether the element is enabled.
  7. Displayed: Checks if the element is displayed.
    • Returns a bool indicating whether the element is displayed.
  8. Text: Gets the visible text of the element.
    • Returns a string containing the visible text.
  9. TagName: Returns the tag name of the element.
    • Returns a string representing the tag name (e.g., div, input).
  10. GetAttribute(string attributeName): Gets the value of the specified attribute.
    • Returns a string containing the value of the specified attribute.
  11. GetCssValue(string propertyName): Gets the value of a CSS property.
    • Returns a string containing the value of the specified CSS property.
  12. Location: Gets the location of the element.
    • Returns a Point object representing the x and y coordinates of the element.
  13. Size: Gets the size of the element.
    • Returns a Size object representing the width and height of the element.
  14. Rect: Gets the location and size of the element as a rectangle.
    • Returns a Rectangle object containing the location and size.
  15. FindElement(By by): Finds the first child element using the given method.
    • Returns an IWebElement representing the found element.
  16. FindElements(By by): Finds all child elements using the given method.
    • Returns an IList containing all matching child elements.

Implicit Wait

Implicit wait instructs WebDriver to wait for a certain amount of time when trying to find an element if it is not immediately available. It sets a default wait time for the entire duration of the WebDriver session.

                    
                        // Set implicit wait
                        driver.Manage().Timeouts().ImplicitWait(TimeSpan.FromSeconds(10));
                        // Open a website
                        driver.Navigate(GoToUrl("http://example.com"));
                        // Interact with elements
                        // WebDriver will wait up to 10 seconds for elements to be found
                        driver.FindElement(By.Id("someElementId")).Click();
Explicit Wait

Explicit wait allows you to specify a certain condition to wait for before proceeding further in the code. It provides more flexibility compared to implicit wait as you can target specific elements and conditions.

                    
                        // Define explicit wait
                        WebDriverWait wait = new WebDriverWait(driver, TimeSpan.FromSeconds(10));
                        // Wait for element to be visible and interact with it
                        IWebElement element = wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.VisibilityOfAllElementsLocatedBy(By.Id("someElementId"))).FirstOrDefault();
                        element.Click();
  • VisibilityOfElementLocated(By locator): Waits for an element to be visible
  • ElementToBeClickable(By locator): Waits for an element to be clickable
  • PresenceOfElementLocated(By locator): Waits for an element to be present in the DOM
  • TextToBePresentInElement(By locator, string text): Waits for specific text to be present in an element
                    
                        try 
                        {
                            // 1. Element to be visible
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.VisibilityOfAllElementsLocatedBy(By.Id("elementId")));
        
                            // 2. Element to be clickable
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.ElementToBeClickable(By.Id("buttonId")));
        
                            // 3. Element to be present in the DOM
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.PresenceOfAllElementsLocatedBy(By.Id("someId")));
        
                            // 4. Element to be selected (Checkbox or radio button)
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.ElementToBeSelected(By.Id("checkboxId")));
        
                            // 5. Element to be selected (for any condition)
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.ElementToBeSelected(By.Id("checkboxId")));
        
                            // 6. Alert to be present
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.AlertIsPresent());
        
                            // 7. Title to be
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.TitleIs("Expected Page Title"));
        
                            // 8. Title contains
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.TitleContains("Expected"));
        
                            // 9. Text to be present in the element
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.TextToBePresentInElementLocated(By.Id("someElementId"), "Expected Text"));
        
                            // 10. Text to be present in an element's value
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.TextToBePresentInElementValue(By.Id("someElementId"), "Expected Text"));
        
                            // 11. Stale Element Reference Exception
                            IWebElement staleElement = driver.FindElement(By.Id("someId"));
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.StalenessOf(staleElement));
        
                            // 12. URL contains
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.UrlContains("expected"));
        
                            // 13. URL to be
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.UrlToBe("https://example.com/somepage"));
        
                            // 14. Presence of multiple elements
                            wait.Until(SeleniumExtras.WaitHelpers.ExpectedConditions.PresenceOfAllElementsLocatedBy(By.ClassName("multipleElements")));
                        }
                        catch (TimeoutException e) 
                        {
                            Console.WriteLine("Timed out waiting for conditions to be met.");
                        }
                        finally 
                        {
                            driver.Quit();
                        }
Fluent Wait

Fluent wait is a more advanced type of explicit wait that allows you to set the maximum amount of time to wait for a condition, as well as the frequency with which to check the condition. Additionally, you can ignore specific types of exceptions while waiting.

Use fluent wait when you need more control over the waiting behavior, such as polling intervals and exception handling.

                    
            // Define fluent wait
            FluentWait<> wait = new FluentWait(driver)
                .WithTimeout(TimeSpan.FromSeconds(10))
                .PollingEvery(TimeSpan.FromSeconds(1))
                .Ignoring(Exception);
            
            // Wait for element to be present and interact with it
            IWebElement element = wait.Until(new Func<IWebDriver, IWebElement> (driver) =>
            return driver.FindElement(By.Id("someElementId"));
            );
            element.Click();
Action API 

    // Click() - Clicks on a web element.
    new Actions(driver).Click(element).Perform();

    // ClickAndHold() - Clicks (without releasing) at the current mouse location or on a given element.
    new Actions(driver).ClickAndHold(element).Perform();

    // ContextClick() - Performs a right-click at the current mouse location or on a given element.
    new Actions(driver).ContextClick(element).Perform();

    // DoubleClick() - Performs a double-click at the current mouse location or on a given element.
    new Actions(driver).DoubleClick(element).Perform();

    // DragAndDrop() - Drags an element from a source location and drops it at a target location.
    new Actions(driver).DragAndDrop(source, target).Perform();

    // DragAndDropBy() - Drags an element from its current location and drops it at an offset.
    new Actions(driver).DragAndDropBy(element, 50, 100).Perform();

    // MoveByOffset() - Moves the mouse from the current position by the given offset.
    new Actions(driver).MoveByOffset(50, 100).Perform();

    // MoveToElement() - Moves the mouse to the middle of the given element.
    new Actions(driver).MoveToElement(element).Perform();

    // Release() - Releases the pressed mouse button at the current mouse location or on a given element.
    new Actions(driver).Release().Perform();

    // SendKeys() - Sends a sequence of keys to the currently focused element.
    new Actions(driver).SendKeys(element, Keys.Enter).Perform();

    // KeyDown() - Performs a key press without releasing it.
    new Actions(driver).KeyDown(Keys.Control).Perform();

    // KeyUp() - Releases a pressed key.
    new Actions(driver).KeyUp(Keys.Control).Perform();

    // Build() - Generates a composite action containing all actions so far.
    Action action = new Actions(driver).MoveToElement(element).Click().Build();
    action.Perform();

    // Perform() - A convenience method for performing the actions built so far.
    new Actions(driver).MoveToElement(element).Click().Perform();
Selenium Exception

Selenium WebDriver can throw various exceptions during the execution of automation scripts. Understanding these exceptions and their solutions is crucial for writing robust and reliable test scripts. Here are some common Selenium C# exceptions and their solutions:

  1. NoSuchElementException

    • Description: Thrown when an element could not be found on the web page.

    • Solution: Ensure the locator used to find the element is correct and wait for the element to be present.

      WebDriverWait wait = new WebDriverWait(driver, TimeSpan.FromSeconds(10));
        WebElement element = wait.Until(ExpectedConditions.ElementIsVisible(By.Id("elementId")));

  2. StaleElementReferenceException

    • Description: Thrown when a reference to an element is no longer valid (e.g., the element has been refreshed or removed from the DOM).

    • Solution: Re-acquire the element reference after the page updates or use explicit waits.

      WebElement element = driver.FindElement(By.Id("elementId"));
        element.Click(); // Re-locate the element if necessary
        element = driver.FindElement(By.Id("elementId"));

  3. TimeoutException

    • Description: Thrown when a command does not complete in the specified timeout period.

  4. ElementNotVisibleException

    • Description: Thrown when an element is present in the DOM but not visible.

    • Solution: Ensure the element is visible before interacting with it or use waits to handle visibility.

      WebDriverWait wait = new WebDriverWait(driver, TimeSpan.FromSeconds(10));
        WebElement element = wait.Until(ExpectedConditions.ElementIsVisible(By.Id("elementId")));

  5. ElementNotInteractableException

    • Description: Thrown when an element is not interactable (e.g., it is disabled or not visible).

    • Solution: Wait for the element to become interactable or ensure it is in the correct state.

      WebDriverWait wait = new WebDriverWait(driver, TimeSpan.FromSeconds(10));
        WebElement element = wait.Until(ExpectedConditions.ElementToBeClickable(By.Id("elementId")));

  6. NoAlertPresentException

    • Description: Thrown when switching to an alert but no alert is present.

    • Solution: Ensure an alert is present before switching to it.

      WebDriverWait wait = new WebDriverWait(driver, TimeSpan.FromSeconds(10));
        wait.Until(ExpectedConditions.AlertIsPresent());
        IAlert alert = driver.SwitchTo().Alert();
        alert.Accept();

  7. InvalidSelectorException

    • Description: Thrown when an invalid selector is used.

    • Solution: Verify the correctness of the selector syntax.

      WebElement element = driver.FindElement(By.CssSelector("valid-css-selector"));

  8. WebDriverException

    • Description: Generic exception thrown when something goes wrong with the WebDriver.
    • Solution: Investigate the root cause by checking the error message and stack trace. Ensure WebDriver and browser versions are compatible.

  9. MoveTargetOutOfBoundsException

    • Description: Thrown when the target for a mouse action is outside the view.

    • Solution: Scroll the element into view before performing the action. 

      WebElement element = driver.FindElement(By.Id("elementId"));
        ((IJavaScriptExecutor)driver).ExecuteScript("arguments[0].scrollIntoView(true);", element);

  10. SessionNotFoundException

    • Description: Thrown when the session ID is not found (e.g., when the session is terminated).

    • Solution: Ensure the WebDriver session is properly initialized and not terminated prematurely.

      IWebDriver driver = new ChromeDriver();
        driver.Navigate().GoToUrl("https://www.example.com");
        driver.Quit();

  11. UnhandledAlertException

    • Description: Thrown when there is an unhandled alert on the web page.

    • Solution: Handle the alert before performing further actions.

      try
        {
            IAlert alert = driver.SwitchTo().Alert();
            alert.Accept();
        }
        catch (NoAlertPresentException e)
        {
            // No alert found, proceed with the test
        }

  12. InvalidElementStateException

    • Description: Thrown when an element is in an invalid state for the action being performed (e.g., trying to send keys to a non-input element).
    • Solution: Ensure the element is in the correct state before performing the action.
    WebElement element = driver.FindElement(By.Id("inputElement"));
        if (element.Enabled)
        {
            element.SendKeys("text");
        }
Page Factory

Page Factory -

Page Factory is a class in Selenium that supports the Page Object Model (POM) design pattern by providing a way to initialize web elements defined in Page Objects. It makes the code more readable and easier to maintain by automatically initializing web elements at runtime using the [FindsBy] attribute.

Key Components of Page Factory

  1. Page Class: Represents a web page and contains web elements annotated with [FindsBy].
  2. PageFactory Class: Contains the InitElements method to initialize the web elements.

Example Structure

  1. Base Class: Contains common setup and teardown methods.
  2. Page Classes: Represent different web pages and use [FindsBy] for web elements.
  3. Test Classes: Contain test methods that utilize the page classes

Methods in PageFactory

  1. PageFactory.InitElements(IWebDriver driver, object page):

    • Initializes the elements of the given page object.
    • Automatically locates the elements defined by the [FindsBy] attribute. 
    PageFactory.InitElements(driver, this);

Annotations in PageFactory

  1. [FindsBy]:

    • Used to locate elements using different strategies (id, name, className, xpath, etc.).
    [FindsBy(Id = "username")]
        private IWebElement usernameField;

  2. [FindsBys]:

    • Used to locate elements using multiple criteria (AND condition).
    [FindsBys(FindsBy(How = How.ClassName, Using = "class1"), FindsBy(How = How.ClassName, Using = "class2"))]
        private IWebElement element;

  3. [FindsAll]:

    • Used to locate elements using multiple criteria (OR condition).
    [FindsAll(FindsBy(Id = "username"), FindsBy(Name = "username"))]
        private IWebElement usernameField;
